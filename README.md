One dad joke, at most 200 characters, for make.fun's **Dad Joke Showdown** bounty ($5 in USDC).

## The joke

> I told my AI agent a joke about recursion. It laughed, then told the same joke again, and again, until I unplugged it.

## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the joke to `/output/entry.txt` (or `out/entry.txt` with the command above).
